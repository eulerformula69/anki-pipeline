# anki-pipeline

Приложение превращает готовый ответ LLM в колоду Anki.

Цепочка состоит из трёх действий:

1. Вставить ответ LLM или загрузить `.txt`.
2. Проверить и отредактировать карточки.
3. Создать и скачать `.apkg`.

Для японских карточек приложение автоматически подготавливает текст для поиска
аудио: `関[かん]する` превращается в `関する`. Кнопка «Найти аудио» ищет точную запись
носителя на Wikimedia Commons. Найденный файл сохраняется в проекте и попадает
в `.apkg`. Если открытой записи нет, интерфейс предлагает поиск на Forvo и
позволяет загрузить MP3, OGG, OGA или WAV вручную.

В проекте нет скачивания видео, транскрипции, распознавания речи, кадров, Ollama и Gemini.

## Запуск

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m src.gui
```

Либо запустите `start.bat`. Интерфейс откроется по адресу <http://127.0.0.1:7999>.

## Формат ответа LLM

Одна карточка занимает одну строку:

```text
ID | type | question | answer
1 | recall | Что такое градиент? | Вектор частных производных.
2 | application | Найдите производную \(x^2\). | \(2x\).
```

Допустимые типы: `recall`, `application`, `discrimination`, `cloze`.

Промпт для генерации карточек хранится в `notebooklm-prompt.md`. Его также можно открыть с главной страницы приложения.

## Данные

Каждый проект хранится в `output/<project-id>/`:

- `project.json` — название и текущее состояние карточек;
- `deck.apkg` — последняя созданная колода.
- `media/` — аудиофайлы карточек и данные об их источниках в `project.json`.

Каталог `output` не входит в Git. Для переноса проекта скопируйте его папку целиком.

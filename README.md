# anki-pipeline

Приложение превращает готовый ответ LLM в колоду Anki.

Цепочка состоит из трёх действий:

1. Вставить ответ LLM или загрузить `.txt`.
2. Проверить и отредактировать карточки.
3. Скачать `.apkg` или отправить карточки в Anki через AnkiConnect.

## Импорт через AnkiConnect

Откройте Anki с установленным дополнением AnkiConnect. После проверки карточек
внизу страницы выберите «В Anki». Приложение получит список колод из открытого
профиля Anki. Выберите колоду и нажмите «Импортировать в Anki».

В «Настройках AnkiConnect» можно изменить адрес подключения
(по умолчанию `http://127.0.0.1:8765`) и указать ключ API, если он задан
в дополнении. Кнопка «Сохранить и проверить связь» сохраняет настройки только
после успешного подключения. Они общие для всех проектов и хранятся локально
в `output/anki-connect.json`, вне Git. Ключ не возвращается в страницу.
При смене настроек сохранённый ключ нужно ввести снова.

Импорт переносит включённые сохранённые карточки, теги и аудио.
Перед отправкой сохраните изменения карточек. Для новых карточек приложение
создаёт тот же шаблон, который использует экспорт `.apkg`.
Через AnkiConnect отправляются только новые карточки. Приложение не меняет
содержимое существующих заметок, их колоду или прогресс обучения. Правьте их в Anki.
Перед отправкой видны название проекта, выбранная колода и число новых карточек.
Успешная отправка каждой карточки записывается в `output/<project-id>/anki-sent.json`.
При повторной отправке эти карточки пропускаются, даже если вопрос изменён в проекте.
Сохраняйте журнал вместе с проектом. После удаления карточки в Anki журнал
по-прежнему считает её отправленной. При смене профиля Anki журнал остаётся общим.

Старые карточки распознаются по прежним служебным тегам или по проекту,
вопросу и типу карточки. Они пропускаются без изменений. Новые хеш-теги
не создаются ни при отправке, ни в `.apkg`. Создание дублей через AnkiConnect
дополнительно запрещено. Снятие флажка «Включить» не удаляет карточку в Anki.

Если связь оборвётся, приложение покажет число завершённых операций.
После восстановления связи повторите отправку. Карточки с сохранённой записью
об отправке будут пропущены. Если Anki принял карточку, но ответ потерялся,
проверка существующих заметок найдёт её по сохранённому вопросу и проекту.
AnkiWeb синхронизируется средствами самого Anki.

Экспорт `.apkg` содержит все включённые карточки. Создание файла не означает,
что его импортировали в Anki, поэтому журнал отправки при этом не меняется.
Повторный импорт `.apkg` обрабатывает сам Anki и может обновить заметки.

Для японских карточек приложение автоматически подготавливает текст для поиска
аудио: `関[かん]する` превращается в текст `関する` и чтение `かんする`. Кнопка
«Добавить аудио» сначала проверяет словарные записи JapanesePod101, затем
Wikimedia Commons. Если запись не найдена или поиск недоступен, приложение
создаёт озвучку японским голосом Nanami через edge-tts, без оплаты и ключа API.
Для синтеза сервис Microsoft получает сохранённый текст для аудио. Нужен интернет.
Это неофициальное подключение: при изменениях сервиса может потребоваться обновление edge-tts.
Перед добавлением аудио сохраните изменения карточек. Обрабатываются только включённые
карточки без актуальной записи. Готовые записи, в том числе загруженные вручную,
сохраняются. Если текст или чтение изменились, запись создаётся заново.
Файл сохраняется в проекте, попадает в `.apkg` и передаётся через AnkiConnect.
В карточке указан источник: запись носителя или синтез речи Nanami.
Кнопка «Найти варианты аудио» внутри карточки сохраняет её правки и загружает
варианты из JapanesePod101, Wikimedia Commons и синтезатора Nanami.
Прослушайте варианты и нажмите «Использовать запись» у подходящего.
До выбора текущая запись сохраняется. Повреждённые файлы и записи короче
0,15 секунды отклоняются при загрузке. Проверка не определяет правильность произношения.
Также можно найти запись на Forvo и загрузить MP3, OGG, OGA или WAV вручную.

После выбора своего файла карточка сохраняется автоматически. В `.apkg` аудио
получает имя с датой и хешем проекта, карточки и содержимого. Поэтому медиа из
разных колод не заменяют друг друга в Anki.

В проекте нет скачивания видео, транскрипции, распознавания речи, кадров, Ollama и Gemini.

## Запуск

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m src.gui
```

Либо запустите `start.bat`. Интерфейс откроется по адресу <http://127.0.0.1:7999>.

## Формат ответа LLM

Одна карточка занимает одну строку:

```text
ID | type | question | answer
1 | recall | Что такое градиент? | Вектор частных производных.
2 | application | Найдите производную \(x^2\). | \(2x\).
```

Допустимые типы: `recall`, `application`, `discrimination`, `cloze`.

Также можно вставить Markdown-таблицу с теми же столбцами:

```text
| id | type | question | answer |
| -- | ---- | -------- | ------ |
| 1 | recall | Как сказать «автор» по-японски? | 著者[ちょしゃ] |
```

Заголовок и строка разделителей не создают карточек. Для символа `|` внутри
ячейки используйте `\|`.

Промпт для генерации карточек хранится в `notebooklm-prompt.md`. Его также можно открыть с главной страницы приложения.

## Данные

Каждый проект хранится в `output/<project-id>/`:

- `project.json` — название и текущее состояние карточек;
- `anki-sent.json` – журнал отправленных через AnkiConnect карточек;
- `deck.apkg` — последняя созданная колода.
- `media/` — аудиофайлы карточек и данные об их источниках в `project.json`.

Каталог `output` не входит в Git. Для переноса проекта скопируйте его папку целиком.
